Security & data
  • API keys are stored in chrome.storage.local, scoped to this extension. They are never synced to your Google account.
  • Every API call goes through the extension service worker, which only permits HTTPS (localhost excepted) and never executes remote code.
  • The extension uses no analytics, no tracking, no cookies and no tab/history permissions.
  • For distribution to a team, prefer secure-backend mode so keys never leave your server.
