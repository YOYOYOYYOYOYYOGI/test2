# §16 META ADS STRATEGY + §17 BUDGETS — RANGAT NATURALS

## The CEO call: ads IMMEDIATELY or after organic proof?

**After organic proof — but the clock starts Day 15, not Day 90.**

Reasoning (money-first):
1. A new cosmetics brand with zero reviews running ads on Day 1 = paying ₹150–₹300 per "hmm, who is this?" that never converts. Indian skincare prospecting CPMs are already high (₹100–260) because every D2C brand fights for the same feed.
2. Your **first ad creative must contain proof** (a real testimonial, a real before/after with disclosure, a real unboxing). That proof doesn't exist before ~Day 17.
3. BUT: waiting 90 days wastes the launch window (Oct–Feb = wedding/Diwali season). So: **organic-only Days 1–14 → optional ₹200/day boost Day 15–20 (only on organic-validated reels) → full ads from Day 21 (launch) at ₹500/day.**

**The only pre-launch ad spend that makes sense (Day 15–20, optional):** take your single best organic Reel (reach CTR ≥ 1.5%, 25%+ 3-sec retention) and run it as a **traffic/follower objective at ₹200/day, Ahmedabad only, 20–40F** — goal: followers + waitlist DMs, not sales. If it can't beat organic CTR, kill it and save the money.

**Ad infrastructure (build by Day 14, before any spend):**
- Meta Business Manager + ad account, payment (₹ via card/UPI-supported method), time zone IST.
- **Meta Pixel** on website (if live) + **Conversions API** — events: PageView, AddToCart, InitiateCheckout, Purchase.
- **WhatsApp Business API** connected (Click-to-WhatsApp objective) + the GLOW quick-reply flow.
- **Catalog** (serum, face wash, moisturizer, kits) with the real photos.
- Creative permission forms collected from testers/creators (ad use rights — see §8).
- **Creative bank ready Day 20:** 6 videos (D17 B/A, D19 creator, D21 launch, D22 objection, D24 unboxing, D26 testimonial) + 3 statics (offer card, texture, box-content).

## THE 4 CAMPAIGNS

### CAMPAIGN 1 — "GLOW PROSPECT" (cold, conversions) — LIVE DAY 21

| Element | Spec |
|---------|------|
| **Objective** | Sales (Conversions) — Purchase on website OR Click-to-WhatsApp (run WhatsApp objective as a second ad set if website is new/low-converting — for a new Indian brand, **WhatsApp often wins first month**) |
| **Campaign structure** | 1 campaign → 2 ad sets (A: broad; B: interest) → 3–4 ads each, same creatives |
| **Ad Set A (broad)** | 20–40, Women + Men (80/20), **Ahmedabad + 40km**, no interests, placements: Advantage+ (Reels + Feed + Stories first) |
| **Ad Set B (interest)** | Same age/gender, **All Gujarat** (Ahmedabad, Surat, Vadodara, Rajkot), interests: skincare, vitamin C, sunscreen + brand interests (Plum, Minimalist, Dot & Key, Neutrogena, Cetaphil, Glow) |
| **Creative (4)** | ① D17 before/after (30s cut, disclosed) ② D26 story-testimonial (UGC) ③ D21 launch offer ④ D16 texture + offer card |
| **Hook (creative)** | "4 hafte. 20 aahaiyan. Same light, same angle." / "Naya brand? 4 baar delete karke order kiya — yeh kahani hai." |
| **Primary text** | "Naya brand pehli baar suna? Hum Gujarat se hain — 20 testers, 4 hafte, asli photos (filter nahi). Vitamin C Serum 10%: dull-look ko fresh dikhane me help, 4–6 hafte ka honest timeline. COD + free shipping (launch me). Results har kisi me alag hote hain — yahi hamari sachai. DM 'GLOW' ya yahan order karo. ⬇️" |
| **Headline** | "Pehli 100 orders — FREE Face Wash mini + COD" |
| **CTA button** | "Shop Now" (website) / "Send WhatsApp Message" (WA objective) |
| **Budget** | ₹500/day total (Ad Set A ₹300, B ₹200) |
| **Test period** | 7 days (do NOT touch before Day 4; Meta needs learning data) |
| **Kill/scale rules** | Day 4: ad with CTR < 0.8% AND no ATC → pause. Day 7: keep top 2 by ATC cost, pause rest. Winner: +30% budget every 48h while ATC stable |
| **Success metrics** | ATC ≤ ₹120 (WA objective: conversation ≤ ₹60), CTR (link) ≥ 1.2%, CPA ≤ ₹350 (first month is learning — accept ₹350–450), ROAS ≥ 1.5x (WA: track "WA→order" manually, target 30%+) |

**Why broad works at ₹500/day:** with 1 ad set broad + 3–4 creatives, Meta's algorithm does the audience work — and for skincare, broad frequently beats interest stacks in India (interests = smaller pool = higher CPM + less optimization room).

### CAMPAIGN 2 — "PROOF & LAL" (warm + lookalike) — LIVE DAY 35+ (after 50+ purchases)

| Element | Spec |
|---------|------|
| **Objective** | Sales (Conversions) |
| **Structure** | 1 campaign → 2 ad sets: **A: LAL 1% Purchasers** (once you have 50–100 purchasers; before that, LAL of "IG engagers 90d + video viewers 75%"), **B: Interest stack All-Gujarat** (same as C1-B but with the 2 proven winners only) |
| **Geo** | All Gujarat (add top-3 India cities Day 60+ if ROAS > 2.5x) |
| **Creative** | 3: ① best testimonial story ② Day-28 B/A (new cut) ③ unboxing. Same primary text family, headline: "Aapki jaisi aahaiyon ne try kiya" |
| **Budget** | ₹500–₹1,000/day (start ₹500: A ₹300/B ₹200) |
| **Test period** | 7 days |
| **Success metrics** | CTR ≥ 1.8% (warm should out-click cold), ATC ≤ ₹80, CPA ≤ ₹250, ROAS ≥ 2.5x |
| **Rule** | LAL refresh: re-create LAL every 30 days (purchaser pool grows = better model) |

### CAMPAIGN 3 — "RECOVER" (retargeting stack) — LIVE DAY 25+

| Element | Spec |
|---------|------|
| **Objective** | Sales (Conversions) |
| **Structure** | 1 campaign → 4 ad sets (priority order, exclusions applied): ① **Video viewers 25–75% + IG/FB engagers 90d** (exclude purchasers) ② **Website visitors 180d** (exclude purchasers + ATC) ③ **ATC 30d** (exclude purchasers) ④ **Checkout 30d** (exclude purchasers) |
| **Geo** | Same as prospecting (don't widen retargeting geo — the people are here) |
| **Creative per ad set** | ① proof: Day-28 B/A + "Aapne dekha tha? Yeh asli photos hain" ② objection: D22 "4 darr, 4 jawaab" ③ urgency-real: "X/100 seat bachi — COD" ④ trust: D26 testimonial + "COD. Return bhi hai." |
| **Primary text** | Short, warm, one-line: "Pucha tha? Yeh raha jawaab — COD hai, 4–6 hafte ka honest timeline hai, aur asli photos hain." |
| **Headline** | "Aapka decision, aapke time par — par batch 1 X seat pe rukega" |
| **CTA** | "Shop Now" / "Send WhatsApp Message" |
| **Budget** | ₹200–₹300/day total (split: ① ₹100 ② ₹60 ③ ₹50 ④ ₹30 — scale whichever has CPA ≤ ₹150) |
| **Frequency cap** | Keep impressions/week ≤ 3–4 per person (retargeting fatigue kills new brands faster than prospecting) |
| **Success metrics** | CPA ≤ ₹150 (retargeting should be 2–3x cheaper than prospecting), ROAS ≥ 3x, CTR ≥ 2% |
| **Note** | Retargeting is where the "second look" orders happen — 20–40% of total revenue by Day 60. Never let it go below ₹150/day once audiences exist. |

### CAMPAIGN 4 — "SCALE" (Advantage+/broad scale + new product) — LIVE DAY 60+

| Element | Spec |
|---------|------|
| **Objective** | Sales (Conversions) |
| **Structure** | **Option A (recommended first):** Meta **Advantage+ shopping-style campaign** (1 ad set, 10 creatives, broad, let Meta optimize) — once 100+ purchase events exist. **Option B:** manual: 3 ad sets — broad All-Gujarat / broad top-6 India cities / LAL 1% purchasers (30d). |
| **Geo** | All Gujarat + top-6 India cities (Delhi NCR, Mumbai, Pune, Bangalore, Hyderabad, Jaipur) — with "Indian skin" creative (nationalize the message, keep the founder's voice) |
| **Creative** | 6–10: the 4 proven winners (new cuts) + 2–3 new angles for Sunscreen (wave-2 hero) + 1 founder video + 1 AI-UGC variant (labeled concept) |
| **Budget** | ₹1,000–₹2,500/day (start ₹1,000; +30% every 3 days while CPA ≤ target) |
| **Test period** | 10 days (bigger budget = more learning data) |
| **Success metrics** | Blended CPA ≤ ₹300, ROAS ≥ 2.5x, new-city CPA ≤ 1.3x Gujarat CPA (if a city is 2x worse, pause it) |
| **Sunscreen handoff (Day 60–75)** | 50% of C4 budget on Sunscreen creative (same audiences, new product) — existing buyers cross-sold via Campaign 3's site-visitors ad set with "kit" creative |

### Campaign sequencing summary

```
Day 1–14   : NO ads (organic proof building)
Day 15–20  : OPTIONAL ₹200/day boost on 1 validated organic reel (Ahmedabad, follower/traffic)
Day 21     : C1 LIVE ₹500/day  (launch)
Day 25     : C3 LIVE ₹200/day  (retargeting audiences now exist)
Day 35     : C2 LIVE ₹500/day  (warm + LAL)
Day 60     : C4 LIVE ₹1,000/day (scale + national + sunscreen handoff)
Day 90     : full engine = C1+C2+C3+C4, total ₹2,000–5,000/day, weekly optimization rhythm
```

**Weekly ad operating rhythm (60 min, every Sunday):**
1. Read: CTR, ATC, CPA, ROAS per ad (7-day windows).
2. Kill: bottom 20% (CTR < 0.8% cold / no ATC). Scale: +30% to winners (max +50%/day).
3. Refresh: any creative > 21 days with falling CTR → new cut of same script.
4. Creatives: bank should always hold **≥6 live + 6 in queue** (never run dry).
5. Learn: log winning hook + format in the hook sheet → next week's organic content uses it (organic ↔ ads flywheel).
