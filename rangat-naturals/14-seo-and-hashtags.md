# §14 SOCIAL SEO + §15 HASHTAG FRAMEWORK — RANGAT NATURALS

## Why social SEO is a *sales* channel, not a nice-to-have

Instagram search and YouTube search are where "vitamin c serum price in india" and "skincare routine for oily skin" get answered **daily**. For a zero-budget brand, search content is the only reach that compounds for months (a Reel dies in 48 hours; a search-optimized Short lives). SEO is also how Meta Ads finds you: your on-page keywords improve relevance scoring for ad delivery.

**The 5 places keywords live (in ranking order):**
1. **Name field** (IG) — highest weight, 30 chars
2. **On-screen text / hook text** (IG reads Reel text; YT reads title)
3. **Caption first line** (first ~80 chars = search snippet)
4. **Hashtags** (topic clustering — framework below)
5. **YouTube title + description** (the big long-tail winner)

## PART B: INSTAGRAM SEARCH OPTIMIZATION — THE 12-POINT CHECKLIST

1. **Name field** = "RANGAT Naturals | Indian Skincare" (category keyword inside the name).
2. **Bio line 1** contains the category phrase users type: "Indian skincare."
3. **Every Reel's on-screen hook text** contains the target keyword or its Hinglish form (IG OCRs on-screen text).
4. **Caption line 1** (before the fold) = the search phrase in natural language ("Vitamin C serum kaise use kare — 5 steps").
5. **One dedicated "keyword Reel" per product per month** whose entire job is a search query (title = the query).
6. **Location tags:** Ahmedabad / Gujarat on every Gujarat-anchored post (local search + local feed boost).
7. **Alt text:** write it manually per image/carousel (most brands skip it — it's free). Format: "[Product] being used on real skin, RANGAT NATURALS Indian skincare."
8. **Hashtags: 8–15 per post** from the framework below (never 30 random, never the same 30 every time).
9. **Series naming:** recurring series with searchable names ("Skin 101 #7", "4-Hafte Program") create a searchable brand of content.
10. **Replies are indexed:** comment conversation around the keyword ("oily skin wale…") adds on-page keyword density — seed 2–3 genuine-looking *real* comment prompts.
11. **Consistency window:** post at 7:30–9 PM; the first 60 minutes of engagement decide distribution — founder replies to every comment in that window.
12. **Monthly keyword audit (30 min):** Meta/IG insights → "searches that led to profile" → list top 10 → next month's content is 30% built from that list. (After Day 30 you'll have data; before that, use the bank above.)

# §15 HASHTAG FRAMEWORK

## The principle

Hashtags are **topic clustering + search discovery**, not reach incantations. 30 random hashtags = spam signal + zero relevance. The system: **8–15 tags per post, drawn from 5 sets, rotated weekly so the account never looks identical.**

## The 5 sets

### SET 1 — BRAND (always, 1–2 tags)
- `#RangatNaturals` (primary — build the searchable brand shelf)
- `#AameeSkinAamnoLiye` (signature line tag — Gujarat posts)
- `#RangatGlow` (offer/launch tag)

### SET 2 — PRODUCT (2–3 per post, match the product in the post)
- Vitamin C: `#VitaminCSerum` `#VitaminCIndia` `#SkinGlow`
- Face Wash: `#FaceWash` `#FaceWashIndia` `#CleanSkin`
- Moisturizer: `#Moisturizer` `#GelMoisturizer` `#SkincareRoutine`
- Sunscreen: `#Sunscreen` `#SPF50` `#SunscreenIndia` `#NoWhiteCast`
- (add 2–3 per future product at launch)

### SET 3 — PROBLEM (2–4 per post, match the problem in the post)
`#OilySkin` `#DrySkin` `#DullSkin` `#TannedSkin` `#Pigmentation` `#AcneProneSkin` `#CombinationSkin` `#MonsoonSkincare` `#SummerSkincare` `#WinterSkincare` `#IndianSkin` `#SkincareForOilySkin` `#SkincareForDrySkin`

### SET 4 — LOCATION (1–3 per post; always for Gujarat-anchored content)
`#Ahmedabad` `#Amdavad` `#Gujarat` · Wave 2: `#Surat` `#Vadodara` · Wave 3: `#Rajkot` · National phase: `#Mumbai` `#DelhiNCR` `#Bengaluru` etc. (only when the content targets that city)

### SET 5 — NICHE/COMMUNITY (2–3 per post)
`#SkincareIndia` `#IndianSkincare` `#DesiSkincare` `#SkincareRoutine` `#SkincareTips` `#SkincareEducation` `#SkincareCommunity` `#D2CIndia` `#SupportLocalBrands` `#MadeInIndia`

## Rotation rules
- Every post: **1–2 brand + 2–3 product + 2–4 problem + 1–3 location + 2–3 niche** = 8–15 tags.
- **Never** the exact same tag block twice in a row (rotate within sets).
- **Never** buy/irrelevant tags (#love, #instagood, #follow4follow — they poison relevance).
- Product-launch posts get the full brand set (`#RangatNaturals #RangatGlow #AameeSkinAamnoLiye`).
- Track weekly (30 min, Sunday): impressions from hashtags vs feed vs search → shift set weights (most Indian skincare reach currently comes from search+feed, so keep niche/product sets strong).
