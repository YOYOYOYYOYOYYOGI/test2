Privacy information

Draft for the playable Vesperglen vertical slice · 15 October 2026

Release note: This draft describes the present offline demo. Before a Play Store release, the developer must add their legal identity and working support contact, publish this page at a permanent public URL, and verify the final Android build and all dependencies against the Data safety form.

What the game stores

The game stores your chosen companion, collection, quest progress, inventory, world position and settings in local storage on your browser or device. Saves do not leave your device through any game feature. No account is required.

What the game does not do

This demo does not include analytics, advertising, in-app purchases, social sign-in, cloud sync, location tracking, camera access, microphone access or multiplayer. It does not request dangerous Android permissions. The installed Android wrapper uses bundled game files and is intended to work offline.

Browser hosting

When you visit the browser demo, your browser downloads the game files from the hosting provider. The host may process standard network request metadata such as IP address and user agent under its own policies; this is distinct from the game's local save system. This page must be revised if the production hosting provider or data practices change.

Your choices

You can reset progress by starting a new game. To delete all browser saves and backups, clear site data for the game's website in your browser settings. To delete an Android installation's local data, clear its app storage or uninstall the app. Volume can be set to zero in game settings.

Changes and contact

Any future analytics, accounts or online features will require an updated notice before launch. A developer contact address and responsible entity must be supplied before this game is published commercially.
