# RANGAT NATURALS — CEO Growth Strategy

A complete, ~50-page CEO growth strategy for **RANGAT NATURALS**, a new Indian skincare brand launching from Gujarat.

Built as if the founder put their own money in.

## What's Inside

### 📄 Document (PDF + Markdown)
**`RANGAT_NATURALS_CEO_GROWTH_STRATEGY.pdf`** — Polished ~70-page strategy document with brand styling.

**`rangat-naturals-strategy/RANGAT_NATURALS_FINAL_DOCUMENT.md`** — Source markdown (single consolidated file, ~30,000 words).

### 🎯 Presentation (PPTX)
**`RANGAT_NATURALS_CEO_GROWTH_STRATEGY.pptx`** — 51-slide PowerPoint deck, brand-themed, ready to present to investors/partners.

### 🛠 Source Files
- **`build_pdf.py`** — Reproduces the PDF from markdown
- **`build_ppt.py`** — Reproduces the PPT
- **`rangat-naturals-strategy/_01…_18_*.md`** — Modular source for each of the 18 sections
